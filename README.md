# PlayStation Gaming Lounge & Cafe Website

> A high-energy, responsive web experience designed for an esports gaming center and cafe, featuring gaming zone showcases, tournament schedules, membership pricing, and booking interfaces.

---

## Features

- **Cyberpunk / Neon Gaming Theme**: Modern dark aesthetic with vibrant glowing neon accents, custom gradients, and futuristic typography.
- **Hero & Call-to-Action**: Dynamic hero section with animated headlines, promotional badges, and instant workstation booking actions.
- **Hardware & Arena Highlights**: Feature section highlighting top-tier RTX gaming rigs, 240Hz high-refresh displays, low-latency gigabit fiber, and ergonomic seating.
- **Dedicated Gaming Zones**: Detailed breakdown of available center zones:
  - **PC Gaming Arena**: Esports-grade competitive tournament setups.
  - **Console Lounge**: Next-gen PlayStation 5 and Xbox Series X couch gaming.
  - **VR Immersion Pods**: Room-scale virtual reality experiences.
  - **VIP Streamer Rooms**: Private acoustic booths for teams and content creators.
- **Esports Tournament Hub**: Live tournament board displaying upcoming games, registration deadlines, bracket sizes, and cash prize pools.
- **Cafe & Snack Bar Menu**: Integrated food and beverage section tailored for extended gaming sessions.
- **Flexible Membership Plans**: Clear hourly rates, night-owl passes, and monthly subscription tiers.
- **Animations & Interactivity**: Scroll-triggered animations via AOS and responsive mobile navigation powered by Bootstrap 5.

---

## Tech Stack

- **Markup**: HTML5
- **Styling**: CSS3 (custom gaming theme variables, CSS Grid, Flexbox, glowing box-shadows, keyframe animations)
- **Frameworks & Libraries**:
  - [Bootstrap 5](https://getbootstrap.com/) (responsive grid, navbar, and utility classes)
  - [AOS (Animate on Scroll)](https://michalsnik.github.io/aos/) (entrance animations)
  - [FontAwesome 6](https://fontawesome.com/) (esports, hardware, and social icons)
- **Typography**: Google Fonts ([Orbitron](https://fonts.google.com/specimen/Orbitron), [Poppins](https://fonts.google.com/specimen/Poppins), [Montserrat](https://fonts.google.com/specimen/Montserrat))

## How to Install and Run

This website is ready to run without compiling or installing external server dependencies.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jatin2267/GAming-cafe-website.git
   cd GAming-cafe-website
   ```

2. **Open the web application:**
   - Navigate into the deployment folder and open `index.html` in your web browser:
     - Windows: `deploy-695160b30fcc2914ccee137e\index.html`
     - macOS/Linux: `deploy-695160b30fcc2914ccee137e/index.html`
   - Or start a local web server:
     ```bash
     npx serve deploy-695160b30fcc2914ccee137e
     ```
   - Access the site in your browser at `http://localhost:3000`.
